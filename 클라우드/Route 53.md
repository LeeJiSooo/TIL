## 정의

AWS에서 제공하는 글로벌 클라우드 도메인 네임 시스템(DNS)서비스

- DNS 서비스가 기본적으로 사용하는 포트 번호가 53번(UDP/TCP)이기 때문에 서비스 이름이 Route 53이다.
- 글로벌 서비스(전역 범위):
    - VPC나 서브넷은 특정 리전 및 가용 영역에 종속되어있던 반면, Route 53은 리전을 선택하지 않는 글로벌 서비스이다.
    - 도메인 이름이라는 개념은 위치와 상관없이 어디서나 유일하게 동작해야 하기 때문이다.

## 브라우저 주소창에 도메인을 입력하면 무슨 일이 일어나는가?

DNS는 전 세계에 흩어진 수많은 서버가 각자 담당 구역을 나누어 관리하는 분산 시스템이다. 따라서 단 한 번의 조회가 아니라, 여러 단계를 거쳐 최종 IP주소를 얻어낸다.

1. DNS 리졸버로 요청 전송

사용자가 브라우저에 my-service.com을 입력하면, 사용자의 PC는 통신사나 공용 DNS가 운영하는 DNS리졸버에 조회를 부탁한다.

1. 루트 네임서버 조회

리졸버는 세상의 모든 도메인의 뿌리인 루트 네임서버에 찾아간다. 루트 서버는 .com을 담당하는 TLD네임서버의 위치를 알려준다.

1. TLD(.com)네임서버 조회

리졸버는 .com 네임서버로 찾아가 “my-service.com의 주소가 어디냐”고 물어본다. TLD 서버는 이 도메인의 진짜 관리 책임이 있는 AWS Route53 네임 서버 주소를 리졸버에게 안내한다.

1. Route53(권한 있는 네임서버)조회

리졸버는 Route53에 도달한다. Route53은 이 도메인에 대한 최종 답을 책임지고 반환하는 ‘권한 있는 네임서버’로서 해당 도메인에 등록된 진자 IP주소를 돌려준다.

요청 경로에서의 위치 : Route53은 요청 패킷이 우리 VPC나 EC2 서버에 닿기 이전에, 가장 맨 앞단에서 “이름을 주소로 바꿀 때” 관여한다.(주소가 IP로 바뀐 뒤에야 VPC, 보안 그룹, EC2 순서로 접속이 시도된다.)

## Route 53의 주요 기능

**호스팅 영역 & 레코드**

- 호스팅 영역 : 도메인 하나에 대한 DNS레코드 설정들을 담아두는 폴더/상자
- 레코드 : 도메인 이름과 실제 IP값을 연결해 두는 개별 규칙 문서 ( A 레코드 → my-service.com = 13.125.10.20)
- 위임 : 가비아, 고대디 같은 도메인 구입 사이트에서 도메인을 산 뒤, “이 도메인의 최종 답은 AWS Route 53 호스팅 영역이 담당한다”라고 네임서버 주소를 등록해 줘야 한다.

**보안 및 통합 관리**

IAM과의 통합 : 누구(개발자, CI/CD 등)가 Route 53의 호스팅 영역 레코드를 수정하거나 생성할 수 있는지 권한 판단(IAM)을 거친다.

DNSSEC(DNS Security Extensions) : DNS 응답 중간에 공격자가 가짜 IP 주소를 찔러 넣는 스푸핑 공격을 막기 위한 보안 확장 기능. 디지털 서명을 붙여 무결성을 검증한다.

## Route 53 Resolver(VPC 내부 & 온프레미스 연동)

지금까지는 “외부 사용자가 우리 도메인을 찾는 이야기”였다면, Route 53 Resolver는 “우리 VPC 내부 자원끼리 또는 회사 자체 서버실(온프레미스)과 이름을 주고받는 이야기이다.

회사가 클라우드로 한 번에 이전하지 못했거나, 보안상 사내 IDC(온프레미스)와 AWS VPC를 동시에 연결해서 쓰는 하이브리드 환경일 때 필요하다.

- 인바운드 엔드포인트 : 사내 서버실 장비가 VPC 안쪽에 있는 리소스의 내부 이름(Private DNS)을 조회하기 위해 들어오는 통로
- 아웃바운드 엔드포인트 : 반대로 VPC안의 EC2 인스턴스가 사내 서버실에 있는 고유 서버의 이름이나 IP를 찾으로 밖으로 나가는 통로

## 정리

- Route 53 : 글로벌 범위의 AWS DNS 서비스로, 도메인 이름을 최종 IP 주소로 변화해 주는 ‘권한 있는 네임서버’역할
- 실제 트래픽을 받아서 전달하는 게 아니라, “어느 주소로 찾아가야 할지 표지판을 알려주는 일”까지만 담당한다.
- 사용자 요청이 인프라(VPC/보안 그룹/EC2)에 도달하기 전, 가장 초기 단계에서 작동한다.
- Route 53 Resolver : 외부 도메인 조회할 뿐 아니라, VPC 내부 및 회사 IDC(온프레미스)간에 양방향으로 도메인 이름을 찾아갈 수 있게해주는 기능도 제공한다.
